# Mini CI 1.0.0

Mini CI 1.0.0 is ready for its first public release.

Mini CI is a lightweight local pipeline runner for learning, testing, and automating repeatable development workflows in Ruby.

## Key Capabilities

- YAML pipelines.
- Setup and cleanup hooks.
- Global and item environments.
- Timeouts and retries.
- Conditional execution.
- Matrix builds and controlled parallel workers.
- Local artifacts and manifests.
- Local dependency cache.
- Trusted local Ruby plugins.
- Local run history.
- Local dashboard.
- Stable CLI exit-code contract.
- Gem packaging.

## Installation

```bash
gem build mini_ci.gemspec
gem install ./mini_ci-1.0.0.gem
mini-ci version
```

The gem has not been published to RubyGems unless a release maintainer does that separately.

## Flagship Example

```bash
mini-ci run examples/showcase-pipeline.yml --concurrency 2
```

## Compatibility

Mini CI supports Ruby 3.1 and newer.

## Upgrade Notes From Pre-1.0

- The version is now `1.0.0`.
- The executable is packaged as `mini-ci`.
- Exit codes are documented and stable.
- `--debug` is available for unexpected internal errors.
- Public configuration and architecture documentation now define the stable behaviour.

## Known Limitations

- Local execution only.
- No remote runners or hosted service.
- No secret vault.
- Plugins are trusted arbitrary Ruby code.
- Dashboard has no authentication.
- Dashboard-managed cancellation is best-effort.
