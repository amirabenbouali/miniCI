# Mini CI 1.0.0

Mini CI 1.0.0 is the first stable release of a lightweight local CI-style pipeline runner written in Ruby.

## Key Capabilities

- YAML pipelines.
- Setup and cleanup hooks.
- Global and item environments.
- Timeouts and retries.
- Conditional execution.
- Matrix builds and controlled parallel workers.
- Local artifacts and manifests.
- Local dependency cache.
- Trusted local Ruby plugins.
- Local run history.
- Local dashboard.
- Stable CLI exit-code contract.
- Gem packaging.

## Installation

```bash
gem build mini_ci.gemspec
gem install ./mini_ci-1.0.0.gem
mini-ci version
```

The gem has not been published to RubyGems unless a release maintainer does that separately.

## Flagship Example

```bash
mini-ci run examples/showcase-pipeline.yml --concurrency 2
```

The showcase demonstrates matrix jobs, setup and cleanup hooks, retries, environment variables, artifact collection, and readable summary output.

## Plugins

Plugins are trusted local Ruby files loaded with `--plugin`, `--plugin-dir`, or `.mini-ci/plugins/`. Plugin API version `1` is stable for this release.

## Dashboard

The local dashboard is included. Start it with:

```bash
mini-ci dashboard
```

It has no authentication and is intended for trusted local development only.

## Compatibility

Mini CI supports Ruby 3.1 and newer.

Primary development and CI targets are Unix-like environments. Windows support is not claimed for v1.0 because process-group timeout behaviour has not been verified there.

## Upgrade Notes From Pre-1.0

- The version is now `1.0.0`.
- The executable is packaged as `mini-ci`.
- Exit codes are documented and stable.
- `--debug` is available for unexpected internal errors.
- Public configuration and architecture documentation now define the stable behaviour.

## Known Limitations

- Local execution only.
- No remote runners or hosted service.
- No secret vault.
- Plugins are trusted arbitrary Ruby code.
- Dashboard has no authentication.
- Dashboard-managed cancellation is best-effort.

## Security Notes

Mini CI runs shell commands and plugins with the current user's permissions. Do not run untrusted pipelines or plugins. Remove secrets from debug output, command logs, artifacts, and issue reports.
