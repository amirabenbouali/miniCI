# Assets

This directory contains lightweight repository presentation assets.

Current assets:

- `mini-ci-logo.svg` - simple project logo used in the README.
- `mini-ci-readme-screenshot.png` - project overview image used at the top of the README.

Screenshot checklist for a future GitHub Release:

- `terminal-showcase.png` showing `examples/showcase-pipeline.yml`.
- `matrix-run.png` showing a parallel matrix summary.
- `dashboard.png` showing the local dashboard run list.

Only commit screenshots generated from the real project, keep them reasonably small, and avoid including secrets or local absolute paths.
